# P6・P7・P8以降のスライド構成案

## P6：普及に向けて乗り越えるべき壁

### スライド構成

**タイトル：** P6 普及に向けて乗り越えるべき壁

**メッセージ本文：**
```
AI導入を成功させるためには、5つの壁を乗り越える必要があります。
各壁の具体例と、乗り越えるための要件を明確にすることで、効果的な対策を打つことができます。
```

**5つの壁（各壁に具体例＋乗り越えるための要件を記載）**

---

#### ① 価値の壁

**課題：** AI自体が「業務要求を満たす機能/品質/性能」になっていない

**具体例：**
- 精度：生成された文書が期待と異なる、数値が間違っている
- 根拠提示：なぜその回答になったのか分からない
- 速度：応答が遅く、業務の流れを妨げる
- コスト：ライセンス費用が高く、ROIが見えない
- 社内データ対応：社内の情報にアクセスできず、汎用的な回答しかできない

**乗り越えるための要件：**
- 適切なツール選定（業務要求に合った機能・性能を持つツールの選択）
- 段階的な適用領域の選定（効果が出やすい領域から開始）
- 社内データ連携の実現（SharePoint、データマート等との連携）
- 効果測定と改善サイクル（KPI設定、定期的な評価・改善）

---

#### ② 意識の壁

**課題：** 使う"意義"が腹落ちしていない／使ってよい空気がない（優先度が上がらない）

**具体例：**
- 経営層：「投資対効果が見えない」「リスクが心配」
- 管理職：「今の業務で十分」「変化を起こす余裕がない」
- 一般社員：「AIに仕事を奪われるのでは」「使う時間がない」
- 組織文化：「失敗を恐れる文化」「新しいツールへの抵抗感」

**乗り越えるための要件：**
- 明確な目的とKPI設定（何を目指すか、なぜやるかを明確化）
- 経営層のコミットメント（CTOレベルでの直接推進、予算確保）
- 成功事例の可視化（具体的な効果・ROIの提示）
- 文化変革の推進（「使わなければ損」という文化の醸成）

---

#### ③ 理解の壁（安心含む）

**課題：** どう使うと効くか、何を入力してよいか、どこまで検証するか、が分からない（知識・ルール理解）

**具体例：**
- 使い方：「Copilotの起動方法が分からない」「プロンプトの書き方が分からない」
- 入力データ：「個人情報を入力してよいか」「機密情報は大丈夫か」
- 検証：「生成された内容をどこまで確認すればよいか」「責任は誰が取るのか」
- ルール：「利用ガイドラインが分からない」「禁止事項が不明確」

**乗り越えるための要件：**
- 利用ガイドラインの策定（入力データ、出力物の扱い、禁止事項の明確化）
- セキュリティポリシーの整備（Microsoft 365環境内データは安全、外部データは注意）
- 階層別教育プログラム（経営層、一般社員、推進者向けの研修）
- ナレッジシェアの仕組み（プロンプト集、成功事例、FAQの共有）

---

#### ④ 能力の壁

**課題：** 業務を細分化し、要件・制約・指示・評価観点へ落として回せない（実行スキル）

**具体例：**
- プロンプト設計：「何を聞けばよいか分からない」「期待する回答が得られない」
- 業務分析：「どの業務にAIを適用すべきか分からない」「業務フローへの組み込み方が分からない」
- 評価：「効果をどう測定すればよいか分からない」「改善のポイントが分からない」
- 技術的理解：「VBAマクロとの連携方法が分からない」「既存システムとの統合が難しい」

**乗り越えるための要件：**
- 推進体制の構築（CoE設置、事業部AI推進リーダー（Champion）の任命）
- 技術支援体制（技術アーキテクトによる支援、ベンダー連携）
- 実践的な教育プログラム（ハンズオン演習、ケーススタディ、ロールプレイング）
- 部門別ユースケースの開発（営業、経理、人事等の部門別活用シナリオ）

---

#### ⑤ 習慣の壁

**課題：** アクセス性・想起性・運用フローがなく、継続利用にならない（"使い続ける仕組み"）

**具体例：**
- アクセス性：「Copilotの起動方法が分からない」「どこから使えばよいか分からない」
- 想起性：「使うタイミングが分からない」「業務フローに組み込まれていない」
- 運用フロー：「承認プロセスが不明確」「エラー時の対応方法が分からない」
- 継続性：「最初は使ったが、すぐに使わなくなった」「効果を実感できずに離脱」

**乗り越えるための要件：**
- 使いやすい環境整備（SSO連携、Teams連携、アクセス方法の統一）
- 業務フローへの組み込み（会議→議事録生成、メール→要約・作成支援等）
- フィードバックループ（不満吸い上げ窓口、利用状況モニタリング、課題対応）
- 定着化施策（表彰制度、継続教育、成功事例の横展開）

**主なアクション：**
- 利用ガイドラインの策定

**対応する壁：** ③理解の壁

---

#### ③ 環境・インフラ（Tools）
**目的：** 使いやすい環境整備により、価値の壁と習慣の壁を乗り越える

**主なアクション：**
- ツールの選定・契約
- インターフェースの整備
- 既存システムとの連携

**対応する壁：** ①価値の壁、⑤習慣の壁

---

#### ④ 組織・人材・文化（People）
**目的：** 使いこなせる人と文化を育成し、能力の壁と理解の壁を乗り越える

**対応する壁：** ④能力の壁、③理解の壁、②意識の壁

#### ⑤ プロセス・運用（Operation）

## P8以降：各カテゴリー別の具体的なアクション内容

### P8：戦略・目的（Why & What）

**タイトル：** P8 戦略・目的（Why & What）

**メッセージ本文：**
```
「とりあえずAIを入れてみた」で終わらせないために、最も重要な土台です。
明確な目的とKPI設定により、意識の壁を乗り越えます。
```

**主なアクション：**

#### 1. 目的の明確化（KGI/KPI設定）

**方向性の決定：**
- 業務効率化（マイナスをゼロに）なのか、新規価値創出（ゼロをプラスに）なのかを明確化
- アイリスの場合：P2の戦略に基づき、「圧倒的なスピード」と「完璧な品質」の両立を目指す

**KGI/KPIの設定：**
- 利用率KPI：現状20% → 3ヶ月で50% → 6ヶ月で70% → 12ヶ月で80%
- 時間削減KPI：1人あたり月平均10-15時間の業務時間削減
- 業務効率化KPI：主要業務で20-30%の時間削減
- 部門別KPI：各事業部で5-10件のユースケース創出

#### 2. 適用領域の選定

**段階的展開戦略の決定：**
- 全社一斉導入か、特定部署からのスモールスタートかを決定
- 推奨：スモールスタート（50名→500名→全社の段階的展開）

**優先業務フローの選定：**
- 初期段階（0-6ヶ月）：メール要約、会議要約、文書作成、プレゼン作成
- 発展段階（6-12ヶ月）：SharePoint横断検索、部門特化AIエージェント
- 各事業部の特性に応じた優先順位付け

### P9：ガバナンス・リスク管理（Rules）

**タイトル：** P9 ガバナンス・リスク管理（Rules）

**メッセージ本文：**
```
社員が「安心して」使えるようにするためのガードレールです。
これが曖昧だと、現場は萎縮して使いません。理解の壁を乗り越えます。
```

**主なアクション：**

#### 1. 利用ガイドラインの策定

**入力データのルール明確化：**
- 個人情報、機密情報、顧客データの入力可否を明確化
- 「入力してはいけないもの」をリスト化
- 重要：Microsoft 365環境内データは基本的に安全

**出力物の扱いルール：**
- 生成物の著作権、ファクトチェックの義務を明確化
- 「AIの嘘」への責任の所在を明確化
- 重要：「AIのミスはプロセスの不備」と割り切る免責ルールの作成

**禁止事項の明確化：**
- 競合他社への攻撃的な利用、差別的な生成などの禁止事項を明文化

#### 2. セキュリティポリシー

**セキュリティ設定の確認・最適化：**
- Commercial Data Protectionの確認
- DLP（Data Loss Prevention）ポリシーの設定
- Azure ADによるアクセス制御の確認
- 重要：導入前に専門家による設定レビュー

**監査体制の構築：**
- ログの保存期間の決定
- 監査ログの定期レビュー体制の構築
- インシデント対応マニュアルの作成

### P10：環境・インフラ（Tools）

**タイトル：** P10 環境・インフラ（Tools）

**メッセージ本文：**
```
「使いやすさ」が浸透のスピードを決めます。
適切なツール選定と環境整備により、価値の壁と習慣の壁を乗り越えます。
```

**主なアクション：**

#### 1. ツールの選定・契約

**基本ツールの選定：**
- Microsoft Copilot for Microsoft 365：全社的なAI民主化の基盤として導入（既にライセンス取得済み）
- 自社の既存環境（Microsoft 365）との親和性を確認

**発展段階ツールの検討：**
- Copilot Studio：部門特化AIエージェント構築用（6-12ヶ月後に検討）
- Azure AI Services：高度なAI機能実装用（必要に応じて）

#### 2. インターフェースの整備

**アクセス方法の統一：**
- Webブラウザ版、API連携、Slack/Teams連携Botなどの選択
- 推奨：Microsoft 365環境内での利用を基本とし、Teams連携を強化

**アカウント管理：**
- SSO（シングルサインオン）連携の確認
- 部署ごとの権限設定の設計

#### 3. 既存システムとの連携

**VBAマクロ資産の活用方針：**
- 既存VBAマクロ資産の棚卸し（重要度・使用頻度・置き換え可能性の評価）
- 既存資産は維持しつつ、新規業務からCopilotを活用
- 役割分担の明確化：VBA（定型業務自動化）、Copilot（分析・文書作成）

### P11：組織・人材・文化（People）

**タイトル：** P11 組織・人材・文化（People）

**メッセージ本文：**
```
ツールがあっても「使いこなせる人」がいなければ意味がありません。
体制づくりと教育により、能力の壁と理解の壁を乗り越えます。
```

**主なアクション：**

#### 1. 体制づくり

**中央組織（CoE）の設置：**
- 推奨構成：6-10名
  - AI戦略担当：1-2名
  - 技術アーキテクト：2-3名
  - チェンジマネージャー：1-2名
  - データガバナンス担当：1名
  - プロジェクトマネージャー：1名
- 役割：戦略・ガバナンス・技術支援・標準化・知見共有

**事業部AI推進リーダー（Champion）の任命：**
- 推奨人数：30-50名（部門別に1-3名）
- 選定方法：部門推薦＋自薦、AI活用に前向きな社員
- 役割：部門内での活用促進、質問対応、成功事例共有
- インセンティブ：月額手当（1-3万円）、研修機会、社内表彰

**経営層のコミットメント：**
- AI推進委員会の設置（委員長：取締役CTO、委員：各本部長）
- 月1回の定例会議、予算確保、権限委譲

#### 2. 教育・リテラシー向上

**階層別研修プログラムの構築：**
- 経営層向け：AI投資の意義、リスク、意思決定への活用
- 一般社員向け：プロンプトエンジニアリング基礎、ガイドライン周知（2時間eラーニング）
- 推進者（Champion）向け：高度な活用事例、他社事例の研究（8時間集中研修）

**継続教育体制の構築：**
- 月次：AI活用Tips配信、Q&Aセッション
- 季度：Advanced User Group会合、ベンダー最新情報
- 年次：AIサミット、外部講師招請、認定式

**ナレッジシェアの仕組み：**
- 「すごいプロンプト集」や「成功事例」を共有するチャットチャンネルやWikiの用意
- 定期的な勉強会やLT（ライトニングトーク）大会の開催
- 全社的なAI活用コミュニティ（Teams等）の運営

#### 3. 文化変革

**「使わなければ損」という文化の醸成：**
- 成功体験の即時共有（社内SNS、メールマガジン）
- 管理職の率先活用（トップダウン＋ボトムアップ）

**失敗を恐れない文化の構築：**
- 「AIのミスはプロセスの不備」と割り切る免責ルールの徹底
- 担当者を罰する文化の排除

#### 3. 成功事例の横展開

**成功事例の収集・共有：**
- 事業部ごとの成功事例創出（日立製作所：1,000件横展開を参考）

**表彰制度の構築：**
- 優秀活用部門・個人の表彰、社内報道
- 「Copilotチャレンジカップ」などのコンペ開催（九電グループ事例を参考）

## まとめ：P6-P12の整合性と一貫性

### 構造的な整合性

1. **P6：課題の明確化**
   - 5つの壁を具体例付きで提示
   - 各壁を乗り越えるための要件を明示

2. **P7：解決策の全体像**
   - 5つの壁に対応する5つのカテゴリーを提示
   - 各カテゴリーの概要と対応関係を明示

3. **P8-P12：具体的なアクション**
   - 各カテゴリー別に詳細なアクションを提示
   - 各アクションがどの壁を乗り越えるかを明確化

### メッセージの一貫性

- **P6：** 「5つの壁を乗り越える必要がある」
- **P7：** 「5つのカテゴリーで体系的にアクションを実施」
- **P8-P12：** 「各カテゴリーで具体的なアクションを実施し、壁を乗り越える」

### 視覚的な整合性

- P6：5つの壁を視覚的に表現（各壁に具体例＋要件）
- P7：5つのカテゴリーと5つの壁の対応関係を表で表現
- P8-P12：各カテゴリーの詳細を構造化して表現
