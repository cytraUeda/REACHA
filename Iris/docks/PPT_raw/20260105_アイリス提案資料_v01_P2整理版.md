## P2　アイリスにおけるAI戦略（整理版）

---

## 【スライド作成指示】

### レイアウト構成

**全体構成：上下2段構造**
- **上部（約30-35%の高さ）**：横串メッセージエリア
- **下部（約65-70%の高さ）**：3つの戦略ボックス（横並びまたは2段構成）

---

### 1. タイトルエリア（スライド最上部）

**配置：** スライド上部中央
**フォントサイズ：** 32-36pt
**フォント：** ゴシック体（太字推奨）

**テキスト：**
```
P2　アイリスにおけるAI戦略
```

---

### 2. タイトル直下メッセージ本文（重要：新規追加）

**配置：** タイトル直下、横串メッセージエリアの上部
**レイアウト：** 中央揃え、1-2行で収める
**フォントサイズ：** 18-20pt
**フォント：** ゴシック体（通常または中太）
**背景色：** 白背景、または薄いグレー（#F5F5F5）で軽く強調（自社サンプルに合わせてシンプルに）
**文字色：** ダークグレー（#333333）
**余白：** タイトルから10-15pt、横串メッセージエリアから10-15pt

**テキスト（太字箇所を指定）：**
```
AIを戦略的に活用することで、「**圧倒的なスピード**」と「**完璧な品質**」を両立し、
従来のトレードオフを超えた競争優位を実現する。
```

**強調ポイント：**
- 「**圧倒的なスピード**」→ 太字、赤系（#DC143C）- ポイントとして
- 「**完璧な品質**」→ 太字、赤系（#DC143C）- ポイントとして
- 「**競争優位**」→ 太字、赤系（#DC143C）- ポイントとして（任意）

### 3. 横串メッセージエリア（上部エリア）

**配置：** タイトル直下メッセージの下、スライド上部30-35%のエリア
**レイアウト：** 帯状のボックスまたは背景色付きエリア
**背景色：** ライトグレー（#F5F5F5 または #E8E8E8）- 薄いグレーでセクションを区別
**文字色：** ダークグレー（#333333）
**余白：** 上下左右に20-30pt
**ボーダー：** 1-2pt、ミディアムグレー（#CCCCCC）、シャドウ効果推奨（軽めのドロップシャドウ）
**装飾要素：** 必要に応じて、赤系アウトライン（#DC143C）の楕円やアイコンを配置（ポイントとして）

#### 3-1. ビジョン部分

**配置：** 横串メッセージエリア内、左側または上部
**フォントサイズ：** 
- スローガン：24-28pt（太字）
- サブタイトル：14-16pt（通常）
- 定義文：16-18pt（通常）

**テキスト：**

**ビジョン**
```
世界最速の課題解決企業へ。
〜 Global Local Problem Solver 〜
```

**定義（ビジョン直下または右側に配置）**
```
世界中の「生活の不満」をAIで誰よりも早く見つけ、
開発・検証・業務の自動化により、「日本の品質」を「世界最速」でカタチにして届ける。
```

**強調ポイント：**
- 「**世界最速**」→ 太字、赤系（#DC143C）- ポイントとして
- 「**日本の品質**」→ 太字、赤系（#DC143C）- ポイントとして
- 「**世界最速**」（2回目）→ 太字、赤系（#DC143C）- ポイントとして

#### 3-2. ストーリー部分

**配置：** 横串メッセージエリア内、ビジョンの右側または下部
**フォントサイズ：**
- キャッチコピー：20-22pt（太字）
- 本文：14-16pt（通常）

**テキスト：**

**キャッチコピー（ストーリー冒頭）**
```

```

**本文（2-3行にまとめる）**
```
世界には「速いが品質が低い」企業と、「品質は良いが遅い」企業しかいません。
我々は、「圧倒的なスピード」と「完璧な品質」を両立させます。
```

**強調ポイント：**

**補足メッセージ（任意、小さめのフォントで）**

### 5. デザイン統一ルール

**カラーパレット（白ベース＋薄いグレー＋ポイントのみ赤）：**

- **基本背景色：** 白（#FFFFFF）
  - スライド全体の基本背景色

- **セクション背景色（薄いグレー）：** ライトグレー（#F5F5F5 または #E8E8E8）
  - 横串メッセージエリア、戦略ボックスの背景など、セクションを区別する際に使用
  - 控えめな区別として使用

- **ボーダー・区切り線：** ミディアムグレー（#CCCCCC または #D3D3D3）
  - ボックスのボーダー、区切り線などに使用

- **テキスト色：** ダークグレー（#333333）または黒（#000000）
  - 可読性を最優先に、コントラストを確保

- **ポイント強調色（赤）：** 赤系（#DC143C または #C41E3A）
  - **最重要メッセージ**の強調（例：「AIによる業務の自動化と、自律的な改善」）
  - **数値・キーワード**の強調（例：「圧倒的なスピード」「完璧な品質」）
  - **重要な概念**のアウトライン（楕円、アイコンなど）
  - ポイントのみに使用し、過度な使用は避ける

- **グレー要素（アイコン等）：** ミディアムグレー（#808080）
  - 人物アイコンや補助的な要素
  - 控えめな装飾として使用

- **矢印・接続線：** グレー系（#999999 または #808080）
  - フローや関係性を示す際に使用
  - ポイントが必要な場合は赤系を使用

**フォント統一：**
- タイトル・見出し：ゴシック体（太字）- 自社サンプルと同様のクリーンなフォント
- 本文：ゴシック体（通常）
- 数値・キーワード：ゴシック体（太字）
- 英語表記：サンセリフ体（Arial、Helvetica等）- 自社サンプルの英語表記に合わせる

**装飾要素：**
- **楕円形の強調要素：** 赤系アウトライン（#DC143C）、背景は白 - ポイントとして使用
- **矢印・接続線：** グレー系（#999999 または #808080）、太さ2-3pt - ポイントが必要な場合は赤系を使用
- **アイコン：** グレー系（#808080）の人物アイコンや機能アイコン - 控えめな装飾として使用

**余白・間隔：**
- セクション間：30-40pt
- 要素間：15-20pt
- 行間：1.2-1.5倍

**視覚的階層：**
- 最重要メッセージ：最大フォント、太字、アクセントカラー
- 重要メッセージ：中サイズフォント、太字
- 補足情報：小サイズフォント、通常

**全体的なテイスト：**
- **シンプルでクリーン：** 過度な装飾は避け、機能性を重視
- **色使い：** 基本は白ベース、薄いグレーでセクションを区別、ポイントのみ赤を使用
- **ボックスデザイン：** 角丸は控えめ（2-4pt程度）、シャドウは軽め、ボーダーはグレー系
- **レイアウト：** 整然とした配置、余白を適切に確保
- **統一感：** 白ベース＋薄いグレー＋ポイントのみ赤のテイストを維持
