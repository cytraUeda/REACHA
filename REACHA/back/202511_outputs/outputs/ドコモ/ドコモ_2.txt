- **スマートライフ事業拡大**：ドコモのスマートライフ領域（金融・エンタメ等）の売上が前年比13.6%増の9,044億円に拡大 ([k-tai.watch.impress.co.jp](https://k-tai.watch.impress.co.jp/docs/news/1661419.html#:~:text=%E3%82%BB%E3%82%B0%E3%83%A1%E3%83%B3%E3%83%88%E5%88%A5%E3%81%AB%E8%A6%8B%E3%82%8B%E3%81%A8%E3%80%81%E3%82%B3%E3%83%B3%E3%82%B7%E3%83%A5%E3%83%BC%E3%83%9E%E3%83%BC%E5%90%91%E3%81%91%E3%81%AE%E9%80%9A%E4%BF%A1%E4%BA%8B%E6%A5%AD%E3%81%AF2%E5%85%865139%E5%84%84%E5%86%86%E3%81%A7%E5%89%8D%E5%B9%B4%E5%90%8C%E6%9C%9F%E6%AF%941))。通信以外のサービス収益比率が増加しており、新規サービス・クロスセルで収益多様化を図る潮流が続く。  
- **周波数政策・次世代ネットワーク**：総務省の周波数再編計画で26/40GHz帯の5G割当検討やドローン・上空ネット活用が優先課題に ([k-tai.watch.impress.co.jp](https://k-tai.watch.impress.co.jp/docs/news/1647554.html#:~:text=2024%E5%B9%B4%E5%BA%A6%E7%89%88%E3%81%AE%E3%82%A2%E3%82%AF%E3%82%B7%E3%83%A7%E3%83%B3%E3%83%97%E3%83%A9%E3%83%B3%E3%81%A7%E3%81%AF%E3%80%81%E9%87%8D%E7%82%B9%E7%9A%84%E3%81%AA%E5%8F%96%E7%B5%84%E3%81%A8%E3%81%97%E3%81%A626GHz%E5%B8%AF%E3%81%8A%E3%82%88%E3%81%B340GHz%E5%B8%AF%E3%81%AB%E3%81%A4%E3%81%84%E3%81%A6%E3%80%812025%E5%B9%B4%E5%BA%A6%E6%9C%AB%E3%82%92%E7%9B%AE%E5%87%A6%E3%81%AB%E6%9D%A1%E4%BB%B6%E4%BB%98%E3%82%AA%E3%83%BC%E3%82%AF%E3%82%B7%E3%83%A7%E3%83%B3%E3%81%AB%E3%82%88%E3%82%8A5G%E3%81%AB%E5%89%B2%E3%82%8A%E5%BD%93%E3%81%A6%E3%82%8B%20%E3%81%93%E3%81%A8%E3%82%92%E7%9B%AE%E6%8C%87%E3%81%99%E3%81%BB%E3%81%8B%E3%80%81%E7%84%A1%E7%B7%9ALAN%E3%81%A7%E3%81%AF6GHz%E5%B8%AF%E3%81%AE%E5%B1%8B%E5%A4%96%E5%88%A9%E7%94%A8%E3%80%816))。6G研究も進み、ドコモは6Gの屋内AIテストで通信速度18%向上を実証 ([www.docomo.ne.jp](https://www.docomo.ne.jp/english/info/media_center/pr/2024/1120_00.html#:~:text=telecommunications%20operator%2C%20announced%20today%20that,compared%20to%20conventional%20methods%20indoors))。長期的にネットワーク革新の機運が増している。  
- **カーボンニュートラル**：ドコモグループは2030年カーボンニュートラル宣言を拡張し、2040年までにサプライチェーン含めて温室効果ガス全量ネットゼロを目指すと表明 ([www.docomo.ne.jp](https://www.docomo.ne.jp/english/info/media_center/pr/2023/1106_00.html#:~:text=TOKYO%2C%20JAPAN%2C%20November%206%2C%202023,%E2%80%9D))。環境規制や ESG投資の高まりにより、グリーン技術・省エネ設備への需要が高まっている。  
- **防災・レジリエンス強化**：日本の通信事業者が合同で基地局装備船の共用など災害対応力を強化 ([www.docomo.ne.jp](https://www.docomo.ne.jp/english/info/media_center/pr/2024/1218_00.html#:~:text=Japan%27s%20Telecommunications%20Carriers%20Join%20Forces,and%20other%20key%20assets%20%E2%80%94))。気候変動で大規模災害リスクが増す中、通信インフラの回復力強化が喫緊課題となっている。

# 技術トレンド（代替技術・プラットフォーム動向）  
- **In-Network Computing (INC) / API連携** / 6G時代の新アーキテクチャ。NTTとドコモはIntelやNokiaと共同で、GSMA提唱のOpen Gateway/CAMARA API経由で通信・コンピューティング資源を統合制御する『In-Network Computing』をPoC検証 ([www.docomo.ne.jp](https://www.docomo.ne.jp/english/info/media_center/pr/2025/0303_02.html#:~:text=TOKYO%20,release%20issued%20in%20October%202023))。*補完・代替*：通信＋クラウド連携、エッジ活用。*採用段階*：技術検証（PoC）。*参入障壁*：標準未整備、API実装コスト、パートナー依存。  
  - **統合／移行**：通信ネットワークとMECやクラウドの統合API制御により、エンドツーエンド品質保障が可能。既存5G資産は活用しつつ、新規ソフトウェア導入が必要。TCO低減には運用自動化の取り込みが鍵。  
  - **競合状況/ロックイン**：GSMA/Open Gatewayの標準化進行中。他社（KDDI/SoftBank）も同様技術を模索。API標準採用でロックイン軽減。課金モデルは従来の通信料＋クラウド利用料での二重化リスク。  
  - **代表ソース**：2025年3月3日・NTT DOCOMO（プレスリリース） ([www.docomo.ne.jp](https://www.docomo.ne.jp/english/info/media_center/pr/2025/0303_02.html#:~:text=TOKYO%20,release%20issued%20in%20October%202023))。  

- **3GPP Release 18 (5G-Advanced) / 6G研究** / 5Gの高度化と6G移行。標準化団体3GPPは2024年6月にRel-18 (5G-Advanced) 仕様を完成させた ([www.docomo.ne.jp](https://www.docomo.ne.jp/english/corporate/technology/rd/technical_journal/bn/vol26_2/001.html#:~:text=Abstract%20Standardization%20of%203GPP%20Release,In%20this%20article%2C%20we%20describe))。ドコモ技術陣も標準化に参画。これによりeMBB拡張や新周波数対応、AI/ML支援技術などが包含される見込み。*補完・代替*：現行5Gを深化。*採用段階*：仕様策定完了→機器ベンダーが実装・商用展開段階へ移行中。*参入障壁*：基地局機器/端末ベンダー依存、既設網との互換性検証コスト。  
  - **統合／移行**：Rel-18対応には基地局SWアップデートや新ハードウェア導入が必要。新機能（例：AI制御、低軌道衛星連携等）は次世代設備投資と並行して取り込み。移行期の混在運用でTCO一時増が想定される。  
  - **競合状況/ロックイン**：Ericsson/Nokia/NEC/Huawei等がRel-18機能を開発中。キャリア間で標準主導権争いはないが、ベンダー依存が懸念。価格モデルは機能別アップグレード費用に集約される見通し。  
  - **代表ソース**：2024年6月・NTT DOCOMO（技術記事） ([www.docomo.ne.jp](https://www.docomo.ne.jp/english/corporate/technology/rd/technical_journal/bn/vol26_2/001.html#:~:text=Abstract%20Standardization%20of%203GPP%20Release,In%20this%20article%2C%20we%20describe))。  

- **NTN（非地上系ネットワーク） / HAPS実証** / 地上外からの5G拡大。ドコモ等のコンソーシアムが38GHz帯を用いて高度約4kmの固定翼機（HAPS）から5G通信に成功 ([www.docomo.ne.jp](https://www.docomo.ne.jp/english/info/media_center/pr/2024/0528_00.html#:~:text=With%205G%20evolution%20underway%20and,practical%20application%20of%20HAPS%20networks))。これは気球/ドローンなど高度プラットフォームを用いたNTNの一例で、災害時や離島カバー用途を想定。*補完・代替*：地上基地局を補完。*採用段階*：実証試験段階。*参入障壁*：高コストな機体・機材、周波数調整、法規。  
  - **統合／移行**：従来網にHTS衛星やHAPSシステムを追加する形。データ引き込みに対応可能なコアネットワーク機器が必須で、地上網との回線冗長性設計が必要。TCOは建設コスト高だが、災害時や僻地通信での付加価値が大きい。  
  - **競合状況/ロックイン**：SKY Perfect JSAT等とドコモが共同実施。米国SpaceXやOneWebのLEO衛星とも競合関係。周波数共有技術が進めば複数ベンダー間でのロックイン低減が可能。利用料モデルはMNOのバックホール利用料に近い形態へ。  
  - **代表ソース**：2024年5月28日・NTT DOCOMO（プレスリリース） ([www.docomo.ne.jp](https://www.docomo.ne.jp/english/info/media_center/pr/2024/0528_00.html#:~:text=With%205G%20evolution%20underway%20and,practical%20application%20of%20HAPS%20networks))。  

- **AI強化無線インタフェース** / 6G帯域での通信最適化。ドコモ・NTT・Nokia・SKTが協力し、6G用周波数帯（4.8GHz）でAI制御を加えた屋内試験を実施。従来比最大18%のスループット向上を確認した ([www.docomo.ne.jp](https://www.docomo.ne.jp/english/info/media_center/pr/2024/1120_00.html#:~:text=telecommunications%20operator%2C%20announced%20today%20that,compared%20to%20conventional%20methods%20indoors))。*補完・代替*：AIによるネットワーク制御技術。*採用段階*：実験段階。*参入障壁*：AIモデル開発コスト、機器・アルゴリズムの実装。  
  - **統合／移行**：基地局・端末にAI推論チップ等が必要となり、従来無線機器との混在運用が課題。省スペクトル化が可能だが、実用段階ではAI学習用データや検証インフラ整備に投資が必要。  
  - **競合状況/ロックイン**：世界主要キャリア・ベンダーが6G AI技術を研究中。演算アルゴリズム次第でベンダーロックイン生じる可能性あり。導入初期はPoCパートナー契約モデルが中心か。  
  - **代表ソース**：2024年11月20日・NTT DOCOMO（プレスリリース） ([www.docomo.ne.jp](https://www.docomo.ne.jp/english/info/media_center/pr/2024/1120_00.html#:~:text=telecommunications%20operator%2C%20announced%20today%20that,compared%20to%20conventional%20methods%20indoors))。

# リスク・不確実性  
- **市場予測の変動**：GlobalData等の成長見通しはインターネットユーザ動向に基づくもので、経済状況や新サービス普及速度によって変動する可能性があります（例：人口減少下での需要飽和）。  
- **規制・政策の確度**：MVNO規制緩和や周波数政策の詳細は今後詰められます。法改正の実施タイミングや運用ルール変更により、競争環境・周波数利用計画への影響が不透明です。  
- **技術実用化のタイムライン**：6Gや非地上系ネットなどは研究開発段階であり、商用化には時間がかかる可能性があります。期待される性能（AI統合、超低遅延など）の実現可否やコスト見積もりには不確実性があります。  
- **地域・業種差**：外部データは日本全体の平均傾向を示すため、法人向け需要や特定産業（製造・物流など）でのデジタル投資動向は個別に異なる場合があります。提案時には対象セグメントの実情確認が必要です。  
- **対立する見解**：価格競争が激化する一方で、キャリアはARPU向上策として料金以外の付加価値重視とも表明しており、戦略バランスの解釈には注意が必要です。また、通信事業以外の収益重視と新規投資判断の兼ね合いにも留意が必要です。
