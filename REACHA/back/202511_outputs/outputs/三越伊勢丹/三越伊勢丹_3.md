# 営業での使い方（3案）  

1. **件名案（例）**「富裕層顧客最適化で購買UP」（15字）  
   **アイスブレイク（事実＋解釈）**：「三越伊勢丹は2023年度、首都圏旗艦3店で高付加価値商品が好調です ([www.ryutsuu.biz](https://www.ryutsuu.biz/sales/q100115.html#:~:text=%E4%B8%89%E8%B6%8A5))。インバウンド客・MI会員が平均客単価を押し上げており、次世代顧客戦略が奏功しています。」  
   **ディスカバリー質問**（3-4問）：  
   - 「現在のロイヤル顧客層で購買が伸びているカテゴリーは何でしょうか？」  
   - 「MIアプリや会員データをどう活用して販売促進していますか？」  
   - 「インバウンド対策のKPIは何で設定していますか？（例：免税割合、訪日客客単価など）」  
   - 「仮に主要都市以外の店舗集客を増やすとしたら、どのような施策が考えられますか？」  
   **価値仮説**：「弊社プラットフォームなら、既存会員データをAI分析して**最適な商品提案**や**ターゲットメール**を自動化できます。結果としてVIP層のリピート率向上・単価アップを期待いただけます。」  
   **CTA**：「実際の会員データでデモをご覧いただければ、**具体的な顧客提案例**をお見せできます。ご都合よい日程でお時間いただけませんか？」  
   **反論想定と切り返し**：  
   - *想定反論*：「競合ソリューションは低コストを売りにしているが、御社は高価では？」  
     *切り返し*：「確かに初期投資は重要ですが、当社導入後は**顧客単価＋数%**の改善が先行事例で出ています。単純なコスト比較ではなく、新たな富裕層顧客を引き込む**増収効果**でTCOをご評価いただくとご納得いただけます。」
